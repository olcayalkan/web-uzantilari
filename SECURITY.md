# Güvenlik

## Açık bildirmek

Bir uzantıda güvenlik açığı bulduysan deponun Security sekmesindeki
"Report a vulnerability" bağlantısıyla özel olarak bildir. Herkese açık issue açma.

Bildirime uzantının adını ve sürümünü, açığı tetikleyen adımları, beklediğin ve
gördüğün davranışı yaz.

## Kapsam

| Kapsamda | Kapsam dışı |
|---|---|
| Uzantının sayfaya veri sızdırması, sayfanın uzantıya kod enjekte edebilmesi | Google Translate'in kendi davranışı |
| İzinlerin belgelenenden geniş kullanılması | `chrome://` sayfalarında çalışmama (tarayıcı kısıtı) |
| Depolanan ayarın kötüye kullanılabilmesi | |
